# Как это работает (для автора проекта)

Этот файл для вас: чтобы вы могли объяснить проект и поменять данные без помощи.

## 1. Как запустить

```bash
npm install          # один раз: библиотеки
npx prisma db push   # один раз: создаёт базу prisma/dev.db (старые данные не удаляются)
npm run dev          # запуск на http://localhost:3001
npm test             # 305 проверок
```

Или двойной клик по `start.bat` (делает то же самое). Файл `.env` создаётся из `.env.example`. Остановить сервер: `Ctrl+C`.

## 3. Как работает тест

- Вопросы лежат в `src/data/questions.ts`. Версия 1 — первые 18 (старые результаты), версия 2 — все 24 (вопросы 19–24 о интересах).
- Ответы хранятся в памяти страницы и в черновике браузера (`localStorage`), поэтому обновление страницы их не стирает.
- Устаревший черновик (после правки вопросов) очищается: остаются только подходящие ответы, интерфейс показывает, какой вопрос нужно заполнить.
- При отправке сервер проверяет все ответы и сохраняет их с номером версии.

## 4. Как считаются баллы

Файл `src/recommendation-engine/index.ts`, функция `calculate`. Без случайности и без ИИ.

1. Каждый вариант ответа даёт баллы направлениям (`scores`) и категориям (`categories`, только версия 2).
2. Направление: баллы / максимум × 100. Топ-3 идут в план на 30 дней.
3. Категория (интерес): баллы / максимум × 100.
4. Совпадение с профессией: интересы 45% + направления 35% + школьный предмет 20% (версия 2). Для версии 1 интересов нет, веса 60% и 40%.
5. Каждая профессия получает понятные причины (`reasons`), которые видит пользователь.

Совпадение — ориентир для размышления, а не оценка способностей или вероятность успеха.

## 5. Как выбираются профессии

1. Профессии лежат в `src/data/professions/` (108 штук, по группам категорий).
2. У каждой профессии есть категория и связь с направлениями. Если связь не указана, берутся направления категории (`src/data/categories.ts`).
3. Шаг 2 «Мой путь» показывает 6 лучших по совпадению. Разнообразие: не больше двух из одной категории.
4. Каталог умеет искать по названию и по навыкам, фильтровать, сортировать. Логика в `src/data/catalogQuery.ts`.

## 6. Как сохраняются данные

Файл базы `prisma/dev.db` (SQLite), схема в `prisma/schema.prisma`:

- `Profile` — имя, выбранная профессия.
- `TestResult` — ответы и версия теста. Баллы не хранятся: пересчитываются из ответов.
- `TaskProgress` — отметки заданий плана (ключ плана и id задания).
- `SkillCheck` — самооценка навыков (0, 1, 2).
- `PracticeAnswer`, `LessonRead` — ответы курса по раундам и прочитанные уроки.
- `AiRecord` — сохранённые анализ и дорожная карта ИИ.

Профиль без пароля создаётся при первом сохранении результата; его id лежит в cookie `fp_profile` (httpOnly, secure в production).

Посмотреть базу: `npx prisma studio`.

## 7. Как работает AI API

Файлы в `src/backend/ai/`:

- `config.ts` — провайдер и настройки из `.env`. Для Antigravity: `ANTIGRAVITY_API_URL`, `ANTIGRAVITY_API_KEY`, `ANTIGRAVITY_MODEL`.
- `prompts.ts`, `coach.ts` — что именно уходит модели (только нужные данные, без имени и id профиля).
- `provider.ts` — отправка запроса с таймаутом. В ошибки не попадают ни ключ, ни тело ответа.
- `run.ts` — запуск функции: запрос → извлечение JSON → проверка структуры → при ошибке резерв.
- `schemas.ts`, `json.ts` — проверка формы ответа. Выдуманные проценты, зарплаты, ссылки и навыки вне каталога отклоняются.
- `fallback.ts`, `coach.ts` — резервные тексты по правилам. Всегда помечаются «Резервный режим, это не ответ ИИ».

Подключение: в `.env` заполнить `ANTIGRAVITY_API_KEY`, `ANTIGRAVITY_MODEL`, поставить `AI_PROVIDER="antigravity"`, перезапустить сервер. Подробно: `docs/ANTIGRAVITY_INTEGRATION_RU.md`.

## 8. Как изменить вопрос

Откройте `src/data/questions.ts`, найдите вопрос по `id` (например, `q7`).

- Текст или вариант: поправьте строку `text`.
- Баллы направлениям: число в `scores`, например `{ it: 2, engineering: 1 }`.
- Интересы (вопросы 19–24): поправьте `categories` варианта, например `{ law: 2, social: 1 }`.

Не меняйте `id` вопросов и вариантов: на них ссылаются сохранённые ответы. Если меняете ответы так, что старые перестают подходить, поднимите номер версии (`CURRENT_TEST_VERSION`) и добавьте новую версию в `TEST_VERSIONS`. Потом `npm test`.

## 9. Как добавить профессию

Подробно: `docs/CATALOG_AND_RECOMMENDATIONS_RU.md`, пункт 6.

1. Откройте файл группы в `src/data/professions/`, например `health-social.ts`.
2. Скопируйте блок одной профессии, дайте уникальный `id` латиницей (например `"sports-coach"`).
3. Заполните поля: `title`, `category` (одна из 18 категорий), `description`, `tasks`, `skills` (5–10), `level`, `subjects`, `study`, `projects`, `aiImpact`, `aiAutomates`, `humanSkills`, `growth`.
4. `npm test`. Тесты проверят поля, уникальность `id` и отсутствие процентов и зарплат.

Курс для новой профессии добавляется в `src/data/track.ts` (3 урока и 4 вопроса с пояснениями, по образцу существующих).

## 10. Типичные ошибки

- **Порт 3001 занят.** Закройте другой сервер на 3001 или поменяйте порт в `package.json`. Порт 3000 занят другим проектом, его не трогайте.
- **Ошибка Prisma или «таблица не найдена».** Выполните `npx prisma generate`, затем `npx prisma db push`.
- **Ошибка `EPERM` при `prisma generate`.** Остановите сервер (он держит файл клиента), затем повторите.
- **После `npm run build` dev-сервер ведёт себя странно.** Остановите серверы, удалите папку `.next`, запустите `npm run dev` заново.
- **ИИ отвечает «резервный режим».** В плашке написана причина: нет ключа, неверный ключ, таймаут, лимит или ответ не по формату. Проверьте `.env` и перезапустите сервер.
- **Сменили вопросы, а результат «устарел».** Старые ответы не подходят новым вопросам: пройдите тест заново.
- **В Git попал `.env`.** Немедленно отзовите ключ у провайдера и создайте новый.
