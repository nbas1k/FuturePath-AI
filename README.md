# FuturePath AI

Образовательная платформа, которая помогает выбрать профессию и сразу начать учиться: диагностика интересов и навыков, каталог профессий, короткие интерактивные уроки, симуляции «Один день в профессии», ИИ-наставник и голосовая практика.

Интерфейс на трёх языках: русский, қазақша, English.

## Основные функции

| Раздел | Что умеет |
|---|---|
| Онбординг | 5 шагов: язык, возраст и образование, цель, интересы. Без имени и даты рождения. Отдельные настройки приватности для пользователей младше 18 лет |
| Диагностика | 53 вопроса: интересы по модели RIASEC, условия работы, ситуации, мини-задания, самооценка. Детерминированный подсчёт на сервере, топ-5 профессий с объяснением ([алгоритм](docs/ASSESSMENT_ALGORITHM_RU.md)) |
| Каталог | 114 профессий в 10 направлениях, названия на 3 языках, матрица компетенций, 12 универсальных навыков, вводное задание к каждой профессии |
| Обучение | Карта уроков, 8 типов заданий (выбор, несколько ответов, сопоставление, порядок, пропуски, текст, кейс, мини-проект), проверка ответов на сервере |
| Маршруты | Врач, разработчик, архитектор, предприниматель; 12 универсальных навыков |
| Симуляции | Виртуальная пациентка, план квартиры в масштабе, бизнес-кейс, редактор кода с тестами в изолированном Web Worker |
| ИИ-наставник | Знает профессию, урок и результаты ученика; объясняет, даёт подсказки, разбирает ошибки, не выдаёт готовые ответы |
| Голосовая практика | Распознавание речи в браузере, оценка содержания по рубрике (не голоса и эмоций), текстовая альтернатива |
| Прогресс | XP, уровни, серия занятий, неделя, 10 достижений, освоение навыков по проверенным заданиям, повторение ошибок |
| Аккаунты | Регистрация и вход по email (scrypt, серверные сессии), анонимный прогресс сохраняется при регистрации |
| Админ-панель | Статусы материалов «черновик → на проверке → опубликовано», правка заданий и переводов |

## Технологии

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide
- **Backend:** Next.js Route Handlers, Prisma 6, PostgreSQL (локально или Neon), zod
- **ИИ:** Groq / Anthropic / OpenAI-совместимые API, только на сервере, с лимитами и тайм-аутами
- **Тесты:** Vitest (модульные), Playwright (сквозные сценарии на ширине 320 px и на компьютере)

## Установка и запуск

Нужны Node.js 20+ и PostgreSQL 14+ (или база Neon).

```bash
git clone https://github.com/<owner>/FuturePath-AI.git
cd FuturePath-AI
npm install
cp .env.example .env
```

Заполните `.env`:

- `DATABASE_URL`, `DIRECT_DATABASE_URL`: строка подключения к PostgreSQL
- `AI_PROVIDER` и ключ провайдера (например `groq` + `GROQ_API_KEY` + `GROQ_MODEL`). С `AI_PROVIDER=none` приложение работает без ИИ и честно сообщает, что наставник недоступен
- `ADMIN_SECRET`: секрет входа в `/admin` (не короче 12 символов)

```bash
npx prisma migrate deploy   # создать таблицы
npm run dev                 # http://localhost:3001
```

Учебный контент загружается в базу автоматически при первом открытии раздела «Обучение».

## Проверка

```bash
npm run typecheck

```

## Структура

```
prisma/            схема и миграции БД
src/app/           страницы и API (Next.js App Router)
src/assessment/    вопросы и алгоритм диагностики
src/catalog/       каталог профессий 2.0
src/content/       учебные маршруты и уроки
src/learn/         движок уроков (проверка, состояния, XP)
src/sim/           симуляции
src/voice/         рубрика голосовой практики
src/i18n/          локализация ru / kk / en
tests/, e2e/       Vitest и Playwright
docs/              документация и скриншоты
```

## Важно

- Учебные материалы — черновик, экспертной проверки не проходили. Медицинские, юридические и финансовые задания учебные и не являются консультацией.
- Результат диагностики — подсказка для размышления, а не диагноз и не прогноз успеха; алгоритм не проходил научную валидацию.
- Уроки, симуляции и вопросы диагностики пока только на русском; интерфейс переведён на казахский и английский.
