# FuturePath AI · Melon team · National Founder Cup 2026 (Шымкент)

Зона №3 «THE HUMAN FUTURE». Платформа практической подготовки молодых людей к работе в эпоху искусственного интеллекта.

## О проекте

**Пользователь:** старшеклассник, студент, выпускник, молодой специалист.
**Боль:** требования к навыкам меняются быстрее, чем люди успевают адаптироваться к ИИ. Человек не знает, какие навыки ему нужны, насколько он ими владеет и как эффективно работать с ИИ.
**Решение (AI Readiness):** диагностика без ИИ → пробелы → обучение по ошибкам → работа с ИИ и проверка его подсказок → повторная проверка без ИИ → измеримый результат «было и стало». Профориентация (тест, каталог 108 профессий) остаётся дополнительным инструментом.

**Два пути пользователя на главной:**
1. «Не знаю, какую профессию выбрать»: тест интересов → топ-5 профессий из каталога 108 с объяснением (что совпало, какие навыки развивать, что изменит ИИ, какие человеческие навыки важны, ограничения) → сравнение и кнопка «Выбрать эту профессию» → AI Readiness с рекомендуемым навыком.
2. «Уже знаю свою профессию»: выбор профессии и навыка без теста → AI Readiness.

**Карьерная карта** (Профиль): выбранная профессия, причины рекомендации (если был тест), результаты диагностики, развитые навыки, пробелы и план дальше. Данные сохраняются между посещениями.

**Что уже работает:** из 27 запланированных функций работают 20, частично 3, не реализованы 4 (`docs/AUDIT_27_RU.md`, страница «Все возможности» на сайте). Полный цикл AI Readiness есть для 3 профессий: разработчик программ, UX/UI-дизайнер, маркетолог. Проверено в браузере с настоящим ИИ на чистом профиле: навык «Умение разбивать задачу на шаги» 1 из 3 → 3 из 3 (3 задания на навык: индикатор динамики, не доказательство освоения и не статистика платформы).

Учебный прототип. В проекте нет выдуманных статистик, зарплат и гарантий. Если ИИ недоступен, сайт честно сообщает об этом и ничего не подделывает.

## Стек

Next.js 15 (App Router), TypeScript, Tailwind CSS, Prisma + SQLite, Recharts, Vitest. ИИ: Antigravity Tools (локальный прокси, формат OpenAI chat/completions); поддерживаются также Anthropic и OpenAI-совместимые API.

## Как запустить

Нужен Node.js 20+.

```bash
git clone https://github.com/hackathon-kz/national-founder-cup-shymkent-2026-18-melon-team
cd national-founder-cup-shymkent-2026-18-melon-team
cp .env.example .env      # Windows: copy .env.example .env
npm install
npx prisma db push
npm run dev
```

Сайт откроется на **http://localhost:3001**. На Windows можно дважды нажать `start.bat`.

**Без ключа ИИ** (по умолчанию `AI_PROVIDER="none"`) работают тест, каталог, сравнение и смена профессии, цикл AI Readiness (шаг с ИИ можно пропустить, и это отмечается в итоге), мини-курсы, симулятор, мягкие навыки, карта навыков, аналитика, паспорт, портфолио и ресурсы. Честно сообщают «ИИ не подключён»: AI Mentor, подсказки ИИ, разбор собеседования, сценарии 2030–2035.

**С настоящим ИИ:** запустите Antigravity Tools, в `.env` поставьте `AI_PROVIDER="antigravity"` и впишите `ANTIGRAVITY_API_KEY` и `ANTIGRAVITY_MODEL`. Подробно: `docs/ANTIGRAVITY_INTEGRATION_RU.md`.

Проверки:

```bash
npm run typecheck            # типы
npm run lint                 # линтер
npm test                     # 305 проверок
npm run build && npm start   # production-версия на порту 3001
```

## Структура проекта

```
src/app/                 страницы и API (Next.js): главная, Мой путь, Обучение, Профессии, Профиль, Все возможности (/features)
src/data/                содержимое: 108 профессий, задания цикла (src/data/cycle), реестр 27 функций (features.ts), ресурсы
```

## Безопасность и честность

- Ключи API только в `.env`; правильные ответы и баллы только на сервере; ИИ их не видит и не меняет.
- Каждый ответ ИИ проходит проверку структуры (цифры рынка, зарплаты и ссылки отклоняются).
- Подтверждённый навык = выполнен самостоятельно (от 75% верных). Самооценка подтверждением не считается.
- Личные данные в запросы к ИИ не попадают. Профиль — cookie без пароля, поэтому командных проектов и кабинета преподавателя нет.

## Ограничения

Цикл, курсы, Challenge, симулятор и собеседование только для 3 профессий. Не реализованы: командные проекты, кабинет преподавателя (нужны аккаунты), университеты и тенденции рынка Казахстана (нет проверенных данных). Данные примера и результатов — тестовые прохождения, реальных пользователей пока нет.
