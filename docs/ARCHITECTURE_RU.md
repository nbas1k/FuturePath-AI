# Архитектура FuturePath AI

```
Браузер (React, клиентские компоненты)
   │  показывает только вопросы; правильных ответов нет
   ▼
Next.js 15 (App Router)
 ├─ Страницы (server components): Главная, Мой путь, Обучение, Профессии, Профиль, Все возможности
 ├─ API (route handlers): /api/cycle, /api/challenge, /api/sim, /api/mentor, /api/interview,
 │                        /api/scenarios, /api/soft, /api/portfolio, /api/journey/select, /api/result …
 │      └─ guardSelected: профиль из cookie + выбранная профессия
 ▼
Серверная логика (src/backend, чистые функции в src/cycle, src/skills, src/analytics …)
 ├─ порядок шагов цикла и проверка ответов (правильные ответы только здесь)
 ├─ правила: подбор профессий, карта навыков, итог цикла «было и стало»
 └─ AI-слой (src/backend/ai):
        runAiFeature → запрос → проверка структуры → при ошибке честный отказ/резерв
        │
        ▼
     Antigravity Tools (локальный прокси, формат OpenAI chat/completions) ── ключ только в .env
 ▼
Prisma + SQLite (prisma/dev.db): профили, ответы цикла, подсказки ИИ, история наставника, собеседования,
                                 портфолио, симулятор, мягкие навыки
```

## Данные

- `src/data/professions` (108 профессий), `src/data/cycle` (задания цикла для 3 профессий), `src/data/features.ts` (реестр 27 функций), `src/data/resources.ts` (проверенные ссылки).
- Профиль: httpOnly cookie без пароля. Профиль создаётся при первом действии (выбор цели, тест, мягкие навыки).

## Принципы

1. Правильные ответы и баллы только на сервере.
2. Порядок шагов проверяется на сервере: пропустить или повторить шаг нельзя.
3. ИИ не знает правильных ответов и не меняет баллы.
4. Любой ответ ИИ проходит проверку структуры, запрещены цифры рынка, зарплаты, ссылки.
5. Самооценка не считается подтверждением навыка.
6. Нет выдуманных данных: для университетов и рынка труда функций нет, пока нет проверенных источников.
