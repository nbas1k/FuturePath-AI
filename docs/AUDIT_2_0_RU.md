# FuturePath AI 2.0 — Аудит (Этап 1)

Дата: 2026-11-13. Ветка `futurepath-2.0`, точка восстановления — тег `restore-point-pre-2.0`.

## Стек (проверено по коду)
Next.js 15 (App Router), React 19, TypeScript, Tailwind 3, Prisma 6 + PostgreSQL, Vitest. Neon упомянут в комментариях, но в проекте используется обычный `DATABASE_URL`. Drizzle нет — остаётся Prisma.

## Карта проекта
- `src/app` — страницы: `/`, `/test`, `/result`, `/professions`, `/professions/[id]`, `/learn`, `/path`, `/plan`, `/profile`, `/compare`, `/cabinet`, `/ai`, `/features` и ~30 API-роутов.
- `src/backend` — серверная логика, `src/backend/ai` — слой ИИ.
- `src/data` — тест (`questions.ts`), 108 профессий в 6 файлах, 18 категорий, цикл «проверь → ИИ → заново» для 3 профессий (`data/cycle`).
- `src/recommendation-engine` — детерминированный подсчёт рекомендаций.
- `tests` — 17 файлов, 307 тестов (все проходят).

## Что работает
- Typecheck, 307 unit-тестов, `next build`.
- Страницы открываются (HTTP 200), на 320 px нет горизонтального переполнения (`/`, `/test`, `/professions`, `/learn`, `/profile`).
- Алгоритм рекомендаций детерминирован: 24 вопроса, 6 направлений, 18 категорий, веса 45/35/20 задокументированы в коде.
- ИИ-слой: провайдеры anthropic / openai / compatible / antigravity / groq, ключи только на сервере, тайм-ауты, rate limit (в памяти), fallback-режим.

## Критические находки
1. **База данных недоступна.** `localhost:5432` не отвечает, PostgreSQL и Docker на машине не установлены. Все API с сохранением (профиль, результаты, прогресс) сейчас не работают. Существующих пользовательских данных локально нет (в `prisma/` остались только старые файлы SQLite `dev.db*`, они не читаются текущей схемой).
2. **Нет авторизации.** Идентичность — анонимный `Profile` по cookie `fp_profile`. Нет регистрации, входа, пароля. Прогресс привязан к браузеру, а не к человеку.
3. **Prisma client не был сгенерирован** после установки пакетов (npm заблокировал postinstall). Исправлено командой `npx prisma generate`.
4. **Rate limit в памяти** — сбрасывается при перезапуске и не общий между инстансами.
5. **Тест не соответствует ТЗ:** 24 вопроса вместо 25–35, нет RIASEC, нет разделения интересов / самооценки / продемонстрированных навыков, нет ситуационных задач и практических мини-испытаний, нет «уточнить рекомендации». Нерелевантность вероятна из-за связи «6 направлений → профессии»: многие профессии одной категории получают одинаковый процент (в коде есть обходной `recommendDiverse`).
6. **Каталог:** 108 профессий, но структура не покрывает требования ТЗ (нет названий на kk/en, матрицы компетенций, образовательного маршрута, вводного задания, статуса готовности). 10 направлений ТЗ не совпадают с 18 категориями — нужно отображение.
7. **Только русский язык**, строки зашиты в код. Централизованной локализации нет.
8. **Нет** универсального движка уроков, голосовых заданий, админ-панели, XP/уровней/достижений, E2E-тестов (Playwright установлен, тестов ещё нет).
9. **Дизайн:** верхняя навигация, нет нижней панели на мобильных, нет вертикальной карты уроков.

## План миграции (безопасный)
Принципы: только аддитивные миграции (новые таблицы, новые колонки с default), существующие таблицы и маршруты не удаляются, `id` профессий не меняются.
1. Этап 1 (сейчас): поднять БД → `prisma migrate`/`db push` на пустую локальную базу, зафиксировать baseline.
2. Этап 2: дизайн-система (токены #28A86B), нижняя навигация, onboarding, i18n-каркас (ru/kk/en).
3. Этап 3: новая диагностика (RIASEC + условия работы + ситуации + мини-задания + самооценка), чистые функции с тестами.
4. Этап 4: расширение каталога под 10 направлений и матрицу компетенций.
5. Этап 5+: движок уроков, маршруты (медицина, программирование, архитектура, бизнес), навыки, ИИ-наставник, голос, XP, админка.
6. Авторизация: добавить `User` (email + хеш пароля) и привязку существующего `Profile` к `User` без потери данных.
