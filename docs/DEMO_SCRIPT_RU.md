# Демонстрация на 4 минуты: AI Readiness на чистом профиле

Подготовка: запустить Antigravity Tools (прокси `127.0.0.1:8045`), `start.bat`, открыть сайт в окне с чистым профилем (например, `http://127.0.0.2:3001`: отдельные cookie). `.env` на экране не открывать. Если ИИ не отвечает, показать честное сообщение и пропуск шага (это тоже часть демонстрации).

| Время | Действие | Что сказать |
|---|---|---|
| 0:00–0:25 | Главная: заголовок «Подготовься к работе в эпоху ИИ», шесть этапов, пример с пометкой «Пример» | Одна боль: не понимаю, какие навыки нужны и как работать с ИИ. Одно решение: цикл AI Readiness |
| 0:25–0:45 | «Проверить свои навыки» → выбор «Разработчик программ» (без теста) → навык | Тест не нужен. Для 3 профессий есть полный цикл, для остальных честно показаны ограничения |
| 0:45–1:00 | Этап «Будущее профессии» | Что ИИ берёт на себя и что остаётся человеку. Это не прогноз |
| 1:00–1:35 | Диагностика без ИИ: 3 задания → начальный результат (например, 1 из 3) | Начальный уровень сохранён |
| 1:35–2:10 | План: мини-уроки и упражнения по своим ошибкам; вкладка «Наставник» | Наставник объясняет, но не решает активные задания |
| 2:10–2:50 | Работа с ИИ: подсказки настоящего ИИ, подготовленные утверждения с ошибкой, объяснение решения | ИИ тоже ошибается; проверяем, замечает ли человек |
| 2:50–3:20 | Повторная проверка без ИИ → результат «было и стало» | Показать реальные цифры из этого прохождения, оговорку про 3 задания |
| 3:20–3:45 | Профиль: графики, паспорт навыков → «Все возможности» | 20 из 27 работают, 3 частично, 4 нет, и мы это показываем честно |
| 3:45–4:00 | Итог | Что сделано, что нет, что дальше (аккаунты, данные, пилот) |

Совет: собеседование и сценарии пройти заранее (ответ ИИ занимает до минуты); на видео показать только результат.

Запасной сценарий без ИИ: цель → диагностика → упражнения → пропуск шага с ИИ (с отметкой) → повторная проверка → результат → мягкие навыки → паспорт.
