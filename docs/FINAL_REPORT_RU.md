## Концепция

FuturePath AI — платформа практической подготовки молодых людей к работе в эпоху ИИ. Один пользователь, одна боль, одно решение: проверить и развить навыки, нужные для работы в экономике ИИ (AI Readiness). Профориентация осталась дополнительным инструментом. Состояние по аудиту (`docs/AUDIT_27_RU.md`, реестр `src/data/features.ts`): **работает 20, частично 3, не реализовано 4** из 27. Все 27 видны на странице «Все возможности»; у нереализованных нет кнопки запуска.

## Главный маршрут: AI Readiness (шесть этапов)

Продукт построен вокруг измеримого результата, а не вокруг теста. Пользователь выбирает профессию и навык, проверяет его без ИИ, получает план по своим ошибкам, учится, решает задания вместе с ИИ, проходит независимую повторную проверку и видит сравнение «было и стало». Цикл есть для 3 профессий (разработчик программ, UX/UI-дизайнер, маркетолог), по 3 навыка в каждой, по 3 критерия на навык.

| Шаг | Что происходит |
|---|---|
| 1. Цель | Выбор навыка профессии |
| 2. Будущее профессии | Что ИИ может взять на себя и что остаётся важным (из каталога, помечено «не прогноз») |
| 3. Диагностика | 3 задания без ИИ по 3 критериям, начальный уровень сохраняется |
| 4. План и обучение | Для каждого критерия с ошибкой: мини-урок и упражнение с обратной связью (по ошибкам, не общие советы) |
| 5. Человек + ИИ | 3 сопоставимых задания с подсказкой настоящего ИИ и 3 подготовленных утверждения «ИИ утверждает…» (часть с ошибкой), чтобы проверить, замечает ли человек ошибки ИИ |
| 6. Повторная проверка | 3 новых задания по тем же критериям, без ИИ |
| 7. Доказательство | Начальный и итоговый результат, исправленные ошибки, что ещё слабо, подтверждён ли навык, что изучать дальше |

AI Mentor знает ошибки диагностики и не отвечает на активные задания цикла (диагностика, упражнения, повторная проверка).

### Реальный пример (тестовый профиль, браузер, настоящий ИИ)

- Навык «Логическое мышление»: начальный результат **1 из 3**, выполнено **2 упражнения** по ошибкам (оба верно), задания с ИИ 3 из 3, из подготовленных утверждений с ошибкой замечено **2 из 2**, повторная независимая проверка без ИИ **3 из 3**. Исправлено 2 ошибки (условия и истинность, следствия).
- Навык «Основы программирования»: начальный результат **1 из 3**, **2 упражнения** (одно решено неверно), повторная проверка **2 из 3**. Исправлена одна ошибка, «Функции» остаются пробелом, и навык честно показан как «пока не подтверждён».

### Что цикл не доказывает

Это 3 задания на навык: учебный индикатор динамики, а не оценка владения навыком или профессией. Если начальный результат максимален, рост показать нельзя, и это сказано в итоге. В тесте настоящий ИИ ответил верно на все задания цикла, поэтому умение замечать его ошибки проверяется подготовленными утверждениями (они помечены как написанные авторами). Повторные задания сопоставимы с диагностикой по критерию, но не идентичны ей. Нужны испытания на реальных учениках.

## Что не сделано

- **Team Project Lab, Teacher Dashboard:** нужны учётные записи, роли и контроль доступа. В проекте демо-профиль по cookie без пароля, поэтому честный кабинет преподавателя с контролем доступа без новой системы входа сделать нельзя.
- **University Navigator Kazakhstan, Career Trends Kazakhstan:** нужны проверенные данные с источниками и датами. У нас их нет, придумывать мы не стали.
- **Цикл, мини-курсы, Challenge, симулятор и собеседование только для 3 профессий** (разработчик, UX/UI-дизайнер, маркетолог). Для остальных 105 профессий доступны каталог, сравнение, смена профессии, мягкие навыки, карта навыков, сценарии, ресурсы, наставник и портфолио.
- **Adaptive Difficulty** работает только в Soft Skills Lab.
- **AI Career Diagnostic** остаётся анализом результата теста, а не полным разбором опыта.

## Как обеспечена честность

- Баллы теста и правильные ответы заданий считает сервер по правилам. ИИ их не меняет и не видит.
- Каждый ответ ИИ проходит проверку структуры. Запрещены проценты, зарплаты, ссылки и выдуманные цифры. Если проверка не пройдена или ИИ недоступен, показывается честное сообщение, а подсказки, оценки и ответы наставника не подделываются.
- «Подтверждённый навык» = от 75% верных ответов на задания, решённые самостоятельно. Самооценка и ответы «с подсказкой ИИ» в подтверждение не идут.
- Сценарии будущего помечены «это не прогноз и не факт». Ссылки на ресурсы проверены на доступность 2026-11-09.
- Ключ ИИ хранится только в `.env` на сервере (файл в `.gitignore`), в браузер не попадает.

## Ограничения

- Демо-профиль без пароля: привязан к cookie браузера.
- Оценки ИИ (собеседование, наставник) могут быть неточными, это сказано в интерфейсе.
- Лимит запросов к ИИ: 40 в час на профиль (настройка приложения).
- Данные хранятся в SQLite, это учебный прототип, а не продакшн-хранилище.
