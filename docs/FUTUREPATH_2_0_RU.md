# FuturePath AI 2.0: что сделано и что нет

Ветка `futurepath-2.0` (точка восстановления: тег `restore-point-pre-2.0`). Подробный аудит: `AUDIT_2_0_RU.md`, алгоритм диагностики: `ASSESSMENT_ALGORITHM_RU.md`.

## Честные ограничения
- **ИИ не подключён** (`AI_PROVIDER=none`, ключей нет). Наставник и ИИ-разбор голоса показывают честное сообщение «недоступно»; работает проверка по рубрике и рекомендации без ИИ. Сам ИИ-код проверен только подставным провайдером в тестах, с реальной моделью не проверялся.
- **Весь профессиональный контент — учебный черновик**, написан без участия экспертов. В интерфейсе стоит пометка, в админке есть флаг «проверено экспертом».
- **Профили профессий** для диагностики = профили категорий + код Холланда, написанный вручную. Алгоритм не валидирован.
- **Переводы:** интерфейс на ru/kk/en, но вопросы диагностики, уроки, симуляции и описания профессий пока только на русском (явная пометка). Казахский носителем не проверялся.
- **Редактор кода** выполняется в браузере и не может быть проверен сервером: результат — самоотчёт, уровень навыка не повышает.
- **Распознавание речи** зависит от браузера (в Chrome аудио уходит сервису браузера, об этом сказано в согласии).
- **Нет полноценной авторизации** (регистрация/вход): профиль привязан к cookie браузера. Админка защищена отдельным секретом.
- **Не сделано:** портфолио из результатов уроков (остался старый раздел), экспертные курсы для остальных 110 профессий, диалоговые симуляции с ИИ-персонажем, голосовые уроки внутри карты, часовой пояс пользователя для серий.
- Деплой не выполнялся. Для Neon нужно заменить `DATABASE_URL` и `DIRECT_DATABASE_URL`.
