# Размещение в интернете: варианты и ограничения

Ничего не развёрнуто и не опубликовано. Это подготовка. В проекте есть `Dockerfile` и `.dockerignore` (образ не собирался: на этом компьютере нет Docker).

## Что важно знать про проект

- Next.js 15 + Prisma + **SQLite** (файл базы). Нужен сервер с **постоянным диском**: на платформах без него база сбрасывается при каждом перезапуске (профили и результаты исчезнут).
- Antigravity Tools работает на **вашем компьютере** (`127.0.0.1:8045`). Размещённый сайт до него не дотянется, поэтому на хостинге сайт работает **без ИИ**: наставник, подсказки в Challenge, разбор собеседования и сценарии честно пишут «ИИ не подключён», остальное работает. Vercel для этого проекта не подходит (нет постоянного диска для SQLite, и ИИ всё равно не подключится).
- Профиль привязан к cookie, без пароля. На публичном сайте у каждого посетителя свой профиль.

## Рекомендация для жюри

1. **Основной вариант без риска:** жюри смотрит PDF и видео с настоящим ИИ, а код запускает локально по README (`start.bat`). Ссылка на публичный сайт не обязательна.
2. **Если нужна живая ссылка:** развернуть Docker-образ на VM с постоянным диском (GCP/Oracle), смонтировать `/data`, оставить `AI_PROVIDER=none`. Сайт будет работать без ИИ. Перед отправкой ссылки пройти на нём сценарий нового пользователя.

## Безопасная демонстрация с настоящим ИИ

- Записать видео на своём компьютере с запущенным Antigravity (ключ только в `.env`, на экране `.env` не открывать).
- Не открывать прокси `8045` в интернет и не делать публичный туннель: у прокси есть только ключ, нет защиты от злоупотреблений, а запросы идут с вашей учётки.
- Если жюри обязательно нужен живой ИИ на размещённом сайте, нужен отдельный ключ с лимитом расходов у провайдера ИИ, а не ваш личный прокси. Это решение за вами.
