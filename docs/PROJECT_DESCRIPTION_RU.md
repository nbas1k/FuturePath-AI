# FuturePath AI: описание проекта (National Founder Cup Shymkent 2026, зона THE HUMAN FUTURE)

## Один пользователь, одна боль, одно решение

**Пользователь:** старшеклассник, студент, выпускник или молодой специалист в Казахстане.

**Боль:** «Я хочу подготовиться к будущей работе, но не понимаю, какие навыки мне нужны, насколько хорошо я ими владею и как эффективно использовать ИИ». Требования к навыкам меняются быстрее, чем люди успевают к ним адаптироваться.

**Решение (AI Readiness):** диагностика без ИИ → выявление пробелов → обучение по ошибкам → работа с ИИ и проверка его подсказок → повторная проверка без ИИ → измеримый результат «было и стало».

Профориентация (тест, подбор, каталог из 108 профессий) осталась дополнительным инструментом. Остальные функции платформы работают на тот же маршрут и перечислены на странице «Все возможности» (`/features`) с честными статусами: 20 из 27 работают, 3 частично, 4 не реализованы.

## Как это работает для пользователя

1. **Цель.** Выбор профессии и навыка, без теста. Показано, что ИИ может взять на себя и что остаётся важным (из каталога, не прогноз).
2. **Диагностика.** 3 задания по 3 критериям навыка, без подсказок ИИ. Начальный уровень сохраняется.
3. **Обучение.** Для каждого критерия с ошибкой мини-урок и упражнение с обратной связью. AI-наставник объясняет тему, но не решает активные задания.
4. **Работа с ИИ.** Задания с подсказками настоящего ИИ, плюс подготовленные утверждения «ИИ утверждает…», часть с ошибкой. Пользователь проверяет подсказки и объясняет своё решение.
5. **Повторная проверка.** 3 новых задания без ИИ по тем же критериям.
6. **Результат.** До, после, разница, исправленные ошибки, что ещё слабо, подтверждён ли навык, что изучать дальше.

Полный цикл есть для 3 профессий (разработчик программ, UX/UI-дизайнер, маркетолог): 3 навыка по 3 критерия.

## AI-компоненты

| Компонент | Что делает ИИ | Что делает правило на сервере |
|---|---|---|
| Работа с ИИ в цикле и Human + AI Challenge | Решает задания и объясняет выбор | Знает правильные ответы, сравнивает, считает баллы. ИИ ответов не видит |
| AI Mentor | Ведёт диалог, объясняет ошибки, предлагает упражнения | Блокирует просьбы решить активное задание; хранит историю |
| Тренажёр собеседований | Оценивает ответы по 3 критериям | Проверяет структуру ответа, считает итог |
| Сценарии 2030–2035 | Пишет три качественных сценария | Отклоняет ответ с цифрами, процентами, ссылками |
| AI-диагностика профиля | Объясняет результат теста | Баллы теста считает только правило |

Общее: ключ только на сервере (`.env`), каждый ответ ИИ проходит проверку структуры, при недоступности ИИ пользователь видит честное сообщение, подсказки и оценки не подделываются, а шаг «Работа с ИИ» можно пропустить с отметкой в итоге.

## Измеримый социальный эффект (план, не результат)

Реальных пользовательских данных пока нет, поэтому статистика не приводится. Платформа записывает то, что позволит измерить эффект в пилоте со школьниками и студентами:

- доля пользователей, завершивших цикл;
- разница баллов «до» и «после» по одним критериям (в базе хранится по каждому критерию);
- доля исправленных ошибок;
- доля случаев, когда пользователь заметил ошибку ИИ (по подготовленным утверждениям и по ошибкам реального ИИ);
- число подтверждённых навыков в паспорте навыков.

Ограничение метода: 3 задания на навык дают индикатор динамики, а не оценку владения навыком. Для научной оценки эффекта нужны больше заданий и контрольная группа.

## Бизнес-модель (гипотезы для проверки, без цифр)

- Школы и колледжи: подписка на кабинет преподавателя и отчёты (кабинета пока нет).
- Университеты и работодатели: партнёрские треки навыков и проверка по критериям работодателя.
- Бесплатное ядро для учеников. Проверка этих гипотез ещё не проводилась.

## Честные ограничения

Цикл только для 3 профессий; профиль по cookie без пароля (поэтому нет командных проектов и кабинета преподавателя); нет проверенных данных для университетов и тенденций рынка труда Казахстана; настоящий ИИ в тесте отвечал верно на все задания цикла, поэтому умение замечать ошибки ИИ проверяется и подготовленными утверждениями, помеченными как написанные авторами.
