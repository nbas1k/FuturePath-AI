# Этап 3: AI встроен в путь пользователя

## Где ИИ появляется в пути

| Место | Что делает ИИ | Адрес |
|---|---|---|
| Результат теста (шаг 1) | Объясняет результат простыми словами | `/api/ai` (уже было) |
| Выбор профессии → навыки (шаг 3) | Подсказывает, какие 1–3 навыка развивать, по самооценке | `/api/ai/skill-gap` |
| После первой проверки | Объясняет ошибки и что повторить | `/api/ai/training-feedback` с `kind: "round1"` |
| После повторной проверки | Разбирает результат повторной проверки | `kind: "round2"` |
| Прогресс | Сравнивает результат до и после курса | `kind: "progress"` |
| Раздел «Обучение» → «AI-помощник» | Все AI-функции отдельно: анализ, план, симулятор | `/ai` (уже было) |

ИИ не запускается сам: пользователь нажимает кнопку. Так не тратится лимит без нужды.

## Что ИИ получает и чего не получает

Адрес запроса не содержит данных. Сервер сам читает из базы:
- выбранную профессию и её навыки;
- самооценку навыков (0, 1, 2 или «не отмечено»);
- ответы курса: только **неверные** ответы, с вопросом, ответом пользователя, правильным ответом и пояснением.

Не передаются: имя, id профиля, cookie, ключ API, ответы, которые были верными.

Браузер не может подменить ни навыки, ни ответы: из запроса берётся только тип разбора (`skill-gap`, `round1`, `round2`, `progress`).

## Как ответ проверяется

1. Модель должна вернуть JSON `{summary, focus, nextStep}`.
2. Для навыков: пункты `focus` **обязаны** быть точным названием навыка из каталога. Выдуманный навык отклоняется.
3. Проценты, зарплаты, тенге, ссылки в тексте запрещены.
4. Если проверка не прошла, ошибка сети, таймаут или лимит — показывается резервный текст **с пометкой «Резервный режим, это не ответ ИИ»**.

Резерв собран по правилам: навыки с «пока нет» идут первыми, темы для повторения — из вопросов с ошибками.

## Что видит пользователь

- Плашка «Ответ ИИ · Antigravity Tools / модель» — только для настоящего ответа модели.
- Плашка «Резервный режим, это не ответ ИИ» с причиной — для резерва.
- Внизу: «Разбор не сохраняется и не меняет баллы и правильные ответы».

## Что не меняет ИИ

- Баллы теста (считает `recommendation-engine` без ИИ).
- Правильные ответы курса (лежат на сервере в `src/data/track.ts`).
- Результаты проверок (сохраняются только ответы пользователя).

## Как проверено

- **Реальный ответ модели (Antigravity Tools, `gemini-3.5-flash-lite`):**
  - разбор навыков для «Разработчик программ»: ответ ИИ за ~3 секунды, пункты из каталога;
  - разбор первой проверки: за ~2 секунды, текст опирается на конкретные ошибки пользователя;
  - итог прогресса: за ~2 секунды.
- **Тесты:** 200 из 200. Новые проверки: навык вне каталога отклоняется; проценты и ссылки запрещены; резерв проходит проверку для всех раундов; промпт не содержит личных данных; без ключа сеть не вызывается; ответ с выдуманным навыком уходит в резерв.
- **Ошибки и лимит:** проверены тестами на заглушке (отказ соединения, таймаут, 401, 429, пустой ответ, выдуманный навык). Настоящий прокси с неверным ключом в этом этапе не тестировался.
- **TypeScript, ESLint, production-сборка:** проходят.

## Что по-прежнему не сделано

- Разборы не сохраняются: при перезагрузке их нужно запросить заново.
- Лимит запросов общий на все AI-функции (10 в час по умолчанию) и хранится в памяти сервера.
- Практические задания с ручной проверкой и курсы для других профессий — в этапе 4, если останется время.
