# Этап 4: курсы для большего числа профессий

## Что добавлено

Полный учебный маршрут (проверка → мини-курс → повторная проверка → прогресс) теперь есть для трёх профессий:
- **Разработчик программ** (логика, условия, поиск ошибок) — был в этапе 2;
- **UX/UI-дизайнер** (понятный экран, вопросы при проверке интерфейса, подписи кнопок);
- **Маркетолог** (портрет покупателя, идея рекламы, как понять, что реклама сработала).

Курсы описаны в `src/data/track.ts`. Для каждой профессии: 3 урока и 4 вопроса с пояснениями. Проверка ответов, правила раундов, AI-разборы и прогресс работают так же, как в этапе 2–3.

Страница «Обучение» сама перечисляет профессии, для которых курс есть. Для остальных честно написано, что маршрута пока нет.

## Что это за задания

Это проверка знаний по теме (4 вопроса на профессию), а не практическое задание с ручной проверкой. Вопросы с выбором варианта проверяются сервером. Правильные ответы в браузер не попадают.

## Как проверено

- **Тесты:** 207 из 207. Для каждого курса проверяются: id профессии существует в каталоге, 3 урока, 4 задания, правильный индекс внутри диапазона, варианты не повторяются, нет ссылок, процентов и зарплат.
- **Браузер:** для дизайнера первая проверка дала 4 из 4, три урока отмечены, курс открывается. После проверки выбор профессии возвращён на «Разработчика программ».
- **TypeScript, ESLint, production-сборка:** проходят.

## Что не сделано из этапа 4

Из дополнительных модулей списка задания не реализованы:
- Human + AI Challenge (задание без ИИ и с ИИ, сравнение);
- Soft Skills Lab (коммуникация и решения);
- Team Project Lab (командные проекты);
- Adaptive Difficulty (изменение сложности);
- Future Career Scenarios (сценарии 2030–2035);
- Career Trends Kazakhstan (тенденции, только с проверенными источниками);
- University Navigator Kazakhstan (университеты, только с проверенными данными);
- AI Interview Simulator, Skills Passport, Project Portfolio, Teacher Dashboard.

Причина: каждый из этих модулей требует собственного содержания и проверки. Без проверенных данных о вузах и тенденциях я не стал их добавлять, чтобы не выдумывать факты. Кнопок для них в интерфейсе нет.

## Что изменилось в данных

Новых таблиц нет. Курсы хранятся в коде, а прогресс — в уже существующих таблицах (`PracticeAnswer`, `LessonRead`). Старые данные не удалялись.
