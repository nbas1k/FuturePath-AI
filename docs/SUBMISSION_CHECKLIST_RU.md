## Текст для формы hackathon.kz

**Название:** FuturePath AI

**Короткое описание (до 300 символов):** Платформа практической подготовки молодых людей к работе в эпоху ИИ: диагностика навыков без ИИ, обучение по ошибкам, работа с ИИ с проверкой его подсказок, повторная проверка и измеримый результат «было и стало».

**Полное описание:** Требования к навыкам меняются быстрее, чем молодые люди успевают адаптироваться к ИИ. FuturePath AI ведёт одного пользователя по одному маршруту AI Readiness из шести этапов: цель (профессия и навык, без теста), диагностика без ИИ, обучение по своим ошибкам, работа с ИИ (подсказки настоящего ИИ и проверка его ответов), повторная проверка без ИИ и результат. Правильные ответы и баллы считает сервер, ИИ их не видит. Если ИИ недоступен, сайт честно сообщает об этом. Из 27 запланированных функций работают 20, частично 3, 4 не реализованы (причины в репозитории). Полный цикл есть для 3 профессий. Реальных пользователей пока нет, статистику мы не приводим.

**Стек:** Next.js 15, TypeScript, Tailwind, Prisma + SQLite, Recharts, Vitest; ИИ через Antigravity Tools.

**Зона:** №3 THE HUMAN FUTURE.
