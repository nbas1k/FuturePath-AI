# Демо-видео FuturePath AI: отчёт о создании и проверке

Файл: `docs/demo/FuturePath_AI_demo.mp4` (в Git не добавляется: `*.mp4` в `.gitignore`). Рабочие материалы: `docs/demo/work/` (тоже в `.gitignore`).

## Как сделано
- Сайт запущен в production-режиме (`npm start`, порт 3001), чтобы в кадре не было служебных значков режима разработки.
- Действия записаны Playwright в Microsoft Edge без окна (headless) в новом чистом профиле: без cookie, без теста. Все клики, выбор профессии, ответы и ввод текста выполнены через интерфейс сайта. Результаты не подменялись.
- ИИ настоящий: Antigravity (проверка до записи: ответ 200). Подсказки ИИ в кадре получены в реальном времени (около 16 секунд).
- Итог «1 из 3 → 3 из 3» прочитан со страницы после записи и совпал с закадровым текстом.
- Озвучка: русский голос Windows (Microsoft Irina). Музыка: синтезирована скриптом, внешних файлов и лицензий нет.
- Монтаж: FFmpeg (подписи в нижней полосе, плавные появления и затухания, увеличение блока результата, титульная и финальная карточки).

## Параметры
MP4, H.264 + AAC, 1920×1080, 30 к/с, 3 минуты 25 секунд, около 34 МБ.

## Проверка
- Декодирование без ошибок; разрешение, частота кадров и звук подтверждены `ffprobe`.
- Звук: средняя громкость −19 дБ, пик −1,5 дБ, пауз тишины дольше 3 секунд нет.
- Кадры по всем сценам просмотрены: подписи не закрывают страницу, текст читается, обрезанных элементов нет.
- В кадре нет `.env`, ключей, адресной строки браузера и личных данных. Видна только страница сайта.

## Ограничения
- Озвучка синтетическая; живой голос записать вы можете сами и подложить в тот же монтаж.
- Звук на слух я не прослушивал (нет такой возможности), проверены только уровни и отсутствие пауз. Рекомендуется один раз просмотреть ролик целиком.
- В двух местах из-за закреплённого меню клик выполнен штатно, без плавного движения курсора.
- Пример «До 1 → После 3» на главной помечен как пример; результат в сцене итога реальный из этого прохождения.

## Версия с озвучкой Qwen3-TTS: `docs/demo/FuturePath_AI_demo_Qwen.mp4`

- Модель: Qwen3-TTS-12Hz-0.6B-CustomVoice (официальный репозиторий Qwen на Hugging Face, пакет `qwen-tts`), запуск локально на процессоре. Версия 1.7B и видеокарта не использовались: на диске C оставалось около 5 ГБ, а CUDA-сборка PyTorch и модель 1.7B туда не помещаются.
- Голос: предустановленный мужской голос Aiden (не клон реального человека). Для русского языка выбран по распознаванию речи: 6% ошибок против 12% у Ryan.
- Тестовая озвучка 20 секунд: `docs/demo/FuturePath_AI_voice_test_Qwen_Aiden.wav`.
- Текст диктора тот же, что в первой версии. Изменения: «ИИ» в речи заменено на «искусственный интеллект» (иначе модель читает «и»), бренд произносится как «Future Path AI», в сцену с работой с ИИ добавлены два коротких предложения о том, что показано на экране.
- Дорожка пересобрана из исходных материалов: старой озвучки Windows (Irina) в этом файле нет. Видео, действия на сайте, подписи, переходы и музыка те же. Если новая речь длиннее сцены, последний кадр удерживается.
- Громкость: диктор −17 LUFS, музыка около −33 LUFS (на 16 дБ тише) плюс автоприглушение под голосом; итог −16,7 LUFS, пик −1,5 дБ.
- Параметры: MP4, H.264 + AAC, 1920×1080, 30 к/с, 3 минуты 25 секунд, около 34 МБ.

Проверка: обратное распознавание речи (Whisper small) подтвердило, что весь текст произнесён по порядку и совпадает со сценами; декодирование без ошибок. Естественность интонации и акцент на слух не оценивались (такой возможности нет): Aiden англоязычный голос, говорящий по-русски, поэтому возможен лёгкий акцент.

Рабочие файлы Qwen (модель, окружение, фрагменты озвучки) лежат вне проекта в `C:\Users\БАЙСЕИТ\fp_tts` (около 3,5 ГБ); их можно удалить после утверждения озвучки.
